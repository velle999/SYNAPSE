The wallpaper release. Wallpaper Engine backgrounds run on the SynapseOS
desktop, wallpapers are chosen per monitor rather than all at once, and the
bar's volume module finally has the mixer its tooltip has been promising.

A patch bump: this is 0.2.0's desktop with more on it, not a different one.

## Wallpaper Engine

**Steam Workshop wallpapers now render as your desktop background**
(`Super`+`W`, alongside the static images). Scene and video wallpapers are
drawn by [linux-wallpaperengine](https://github.com/Almamu/linux-wallpaperengine),
which ships on the ISO for the first time, driven through synui's layer-shell
by a new `synui-wpengine` command.

Three honest caveats, because each one costs an afternoon to discover:

- **Web wallpapers render black.** That is upstream, not packaging — it is
  fixed far enough to start CEF cleanly here, and no further.
- **Steam's own Wallpaper Engine can never apply one.** Its Apply button
  drives a Windows API through Proton that has nothing behind it on Linux.
  Subscribe in Steam, apply from `Super`+`W`.
- Some Workshop rows are presets and asset packs rather than wallpapers, and
  nothing can render those.

**Wallpapers are now per monitor.** `Tab` in the picker switches between
setting one output and setting all of them, and each monitor keeps its own
choice across a restart.

Four bugs fixed along the way, all of them the kind that reads as "it's just
slow": every pick sat through a 30-second lock wait (the daemon had inherited
the lock's file descriptor); one untitled wallpaper blanked the rest of the
list; `off` on a single output relaunched the engine it had just stopped; and
the package linked against its own build tree, so it worked only on the machine
that built it.

**Waking from standby no longer drops you back to the static wallpaper.** The
engine cannot rebuild a layer surface once it loses one — its output handler is
a literal `// todo` — so synui restarts it after a resume or an output change.

**And it no longer keeps the machine awake.** `--silent` mutes the engine's own
mixer but still opens a playback stream, which read as active audio and held the
idle inhibitor, so a desktop with a Workshop wallpaper never dimmed, blanked or
locked.

## A real mixer

**Right-clicking the bar's volume module opens a mixer** — output and input
devices with a radio to pick the default, plus a live slider for every
application stream. Drawn by the shell and bound straight to PipeWire, so the
panel, the media keys and synui's own volume knob all track each other.

It replaces a right-click that spawned `pavucontrol`, a program SynapseOS does
not ship — so the tooltip had been advertising a mixer that silently did
nothing.

## Fixes

**Window effects are on a knob** (`Super`+`E`, then `Tab`) — shadow, blur and
corner radius adjustable rather than on-or-off, with the default shadow halved.

**Game mode (`Super`+`G`) now actually frees the GPU.** synapd is socket
activated, so stopping the service left the socket listening and the next client
to connect started it straight back up — usually within a second. Both are
stopped now, and the status line reports what really happened instead of
printing success unconditionally.

**A fresh install no longer opens a fullscreen terminal at every login.** The
installer had been writing that autostart into every new user's config; the live
ISO had already made the opposite call.
