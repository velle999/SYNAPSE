The applications arrive. 0.2.7 was about the desktop — themes that reached past
the compositor, three new layouts, a security repo. This one is about the things
you actually open: a file manager, a package manager, a settings app, a disk
utility, a text editor. Five of them, all new, all built the same way, and all
of them replacing something borrowed.

144 commits, 43 synui releases, six new packages.

## A suite, not a compositor with a menu

SynapseOS shipped a desktop and then asked KDE to do the work. Dolphin managed
your files, there was no package manager but pacman, no settings app at all, no
way to look at a disk, and no editor that came with the system.

Five applications close that, and they are built to one shape: **a C binary that
does the work and prints records, and a quickshell window that only renders
them.** Nothing in the QML knows how to stat a file, resolve a dependency or
read a partition table. Every one of them is therefore usable with no desktop at
all — in a rescue shell, over SSH, from a script — and the window cannot
disagree with the tool, because it has no second opinion to disagree with.

**SYNAPSE Files** (`synfiles`) became the default file manager in August, and it
is the largest of the five: tabs, split view, Icons/Compact/Details, thumbnails,
a folder tree, pinned places shared with Dolphin's own bookmarks, recursive
search by name *or* content, archives, an operation journal behind `Ctrl`+`Z`,
and real drag-and-drop — to another window, to Dolphin, onto the desktop, out to
anything. Delete means the **XDG trash**, the one Dolphin and Nautilus already
use. Dolphin is no longer on the image at all — `synpkg install dolphin` is one
command for anyone who wants the KDE one back.

**SYNAPSE Software** (`synpkg`) is the package manager: one C binary over
`libalpm` covering the Arch repositories, the AUR, Flathub, BlackArch and
SynapseOS's own components, with a CLI, a terminal browser and a window over the
same code paths. Install falls back to the AUR when a name is not in the repos.
It retired `shelly`, which was a shell script pretending to be a package
manager.

**SYNAPSE Settings** (`syn-settings`) is new, and it is the system half of the
configuration the control panel never covered: displays and resolution, keyboard
and language, date and time, network, Bluetooth, power and sleep, kernels,
default applications, and where configuration actually lives. Two rules shape
it. It reports **what the system reports** — every pane reads `localectl`,
`timedatectl`, `wlr-randr`, `rfkill`, `bootctl` on open rather than a cache of
its own — and every row says **which file decided it**, because a default that
came from a fallback and one you chose read identically everywhere else.

**SYNAPSE Disks** (`syn-disks`) reads the storage tree straight out of
`/sys/class/block`, so it still answers in a rescue boot with nothing running.
Drives, partitions, SMART health, mounting, safe removal, formatting and
partitioning — and **formatting anything that shares a physical disk with `/` is
refused outright, with no override**. The check walks the full stack, so an
encrypted container holding a running system is refused even though nothing
reports that partition as mounted.

**`syn-edit`** is the editor: one modal engine behind a terminal editor, a
window, and a scripting mode with no terminal at all — `syn-edit run -k 'ggdG'`
applies keys to a file and prints the result, which is how its own test suite
drives it. The window and a script therefore cannot mean different things by the
same keystroke.

## Kernels are something you choose

The Kernel pane installs, removes and switches kernels on **all three**
bootloaders SynapseOS can install — limine, systemd-boot and GRUB — and it tells
apart the three states that look identical in a package list: *installed*,
*bootable* (an entry exists and an initramfs was actually built), and *running*.
The CachyOS kernels are on offer beside the Arch ones.

That distinction is the whole feature. "Make bootable" used to authenticate
three times and install nothing.

## The ISO stopped carrying a model

The live image no longer ships a 4.1 GB GGUF — about 4 GB off an 8 GB
download — and **the installer asks which model you want** instead: Mistral 7B
(recommended), Phi-3 Mini, Qwen2 0.5B, or none, with the smaller ones flagged
for what they cost in answer quality. The pick is `syn-model`'s own name, so it
is the same one `syn model download` takes later, and the download happens on
the target rather than being copied off the media.

On the live ISO itself, `synapd` now starts in **shell-assist mode** with
nothing to load rather than crash-looping, and says so. `syn status` reporting
"model ✗ not installed" on live media is expected, not a fault to chase.

## Gaming: CachyOS Proton

The installer's Steam option now also installs **`proton-cachyos-slr`** — Valve's
experimental branch plus the CachyOS patch set, built against the same Steam
Linux Runtime — into `/usr/share/steam/compatibilitytools.d`, where Steam finds
it with nothing to copy into `~/.steam`. Valve's Proton stays installed and stays
the default.

It adds CachyOS's repository to do that, and adds it **appended last** in
`pacman.conf` so it can only supply packages no other repository carries.
SynapseOS is Arch: `core` and `extra` keep every package they share.

## The desktop

**Animations are options now.** A window opening can be `off`, `fade` or `rise`
(it glides up into place); switching desktop can be `off`, `fade` or `slide` —
both desks move in the direction you switched. Each has its own length, and they
share one easing curve, in the control panel under *Windows → Animation*.

**A calculator on `Super`+`X`** — type a whole expression, not a four-function
chain; `pi`, `e`, `ans`, `sqrt`/`ln`/`sin` all work, `Up`/`Down` recall the tape,
and `syn-calc` is the same evaluator on the command line.

**Panels are windows.** Each of the pop-up panels can be a floating window you
park, a click-off popup, or closed by its own button — one switch per panel,
because a control panel you want gone the moment you look away and a calculator
you keep in the corner are different answers. They also stay on the monitor they
were opened on instead of chasing the pointer.

**The desktop takes drops.** Drag a file out of Files and onto the wallpaper and
it lands in `~/Desktop`; drag one off the desktop into a window and it goes the
other way. A click on the desktop takes the keyboard, so `Delete` there trashes
the icon under the cursor.

**Text size is a desktop-wide setting**, not a per-application one, and every
window in the suite follows both the family and the scale. Arsenal and Software
were the two that did not; they do now.

**The launcher's own key closes it.** `Super`+`Space` re-pressed while rofi is up
dismisses it, and the modifier tap can be bound to something other than the start
menu. `Super`+`/` then `F2` rebinds a shortcut, tap included.

Date and time: a **date layout you can choose**, 12- or 24-hour, seconds on or
off, and a lock screen that honours the same choice instead of having its own.

## Hardening

A **Lynis audit profile** ships, with the tools to use it. The two root daemons
Lynis flagged are sandboxed, `nvidia-persistenced` — the worst unit on the box —
is sandboxed, the sysctl baseline is extended and a module blacklist added.

**`syn-confine`** is new: run a command inside a kernel-enforced allowlist
(Landlock), with `--rw`/`--ro`/`--rx` paths and outbound TCP denied unless a port
is named. Everything not granted is denied, and the policy is inherited across
`execve`, so a shell cannot escape it by starting something else. **`vibe`'s
shell tool now runs inside one.**

## Fixed

- The equalizer broke audio five separate ways: it muted Bluetooth, sent audio
  to the wrong device when switched off, stopped Bluetooth auto-switching, held
  the idle inhibitor all night, and carried its own volume — at 30%.
- The clipboard history kept nothing at all.
- A maximized window was buried by its own cascade reflow, and a volume change
  shoved background windows in front of what you were using.
- Suspend: a head whose sink dropped before the suspend is re-probed, so DP-3
  comes back.
- Games open on the main screen, and gamescope counts as a game.
- Samsung's printer driver is no longer redistributed; the licences that were
  missing (limine-snapper-sync, chibi, CEF, GraalVM) ship and are named.

## Known issues

- The live ISO has no AI model by design; `synapd` runs in shell-assist mode
  there. Build with `--with-model` if you want the old behaviour.
- Dolphin is off the image and out of the installer's presets and the suggested
  software list. Most of KF6 is still there — kdeconnect pulls it in — so
  `synpkg install dolphin` is 45 packages and ~160 MB rather than the whole
  Qt6/KF6 stack, and one `xdg-mime` command makes it the default again.
