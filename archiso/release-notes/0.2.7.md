## Chibi stops indexing her own filing instructions

Thoth's retrieval corpus is a folder of plain-text primary sources, and the
index was built by globbing `*.txt` inside it. `thoth_corpus/README.txt` — the
note explaining what to *put* in that folder — is a `.txt` sitting in that
folder, so it was chunked and embedded alongside the Kybalion and the Book of
the Dead. Three retrievable passages, cited to a source called "README", any of
which retrieval could hand back as though it were doctrine. One of them carried
the name of the machine the index was built on, so every image shipped a
personal name inside the vector store.

The corpus loader now skips housekeeping files — READMEs, LICENSE/COPYING,
notes and todo files, and anything starting with a dot or an underscore. It is
deliberately not a special case for `README.txt`: the others are the same
mistake waiting for a different filename.

The index was rebuilt from scratch: 9919 passages down to 9916, which is
exactly the three README passages and nothing else. All five source texts keep
their prior counts.

## Dream sync refuses to run on a password everyone has

The dream journal can sync between two Chibis over a LAN, guarded by a shared
token. That token shipped as the literal string `change-this-shared-secret`,
which is not a secret — two machines that both left the default alone would
have happily authenticated each other.

The worse half was the empty case. The check read "no token configured, or the
token matches", so leaving it blank meant **every** request was accepted, on a
listener bound to all interfaces.

Sync now refuses to start without a real shared secret, naming the setting and
the file to put it in. There is no unset-token path left, comparison is
constant-time, and the token is normalised once so a stray newline in one
machine's config cannot make two correctly-configured peers reject each other.
Dream sync is off by default, so this changes nothing for anyone who had not
already turned it on and set a real token.

## Chibi's launcher is unambiguous

Her desktop entry ran `chibi` and let `PATH` decide. With `~/.local/bin` first
on the session `PATH`, that resolved to a development checkout rather than the
installed package on any machine that had one — the dock and the installed app
could silently be two different programs. The entry now names
`/usr/bin/chibi` outright.
