The terminal and the television. 0.2.8 was the release where SynapseOS stopped
borrowing applications — a file manager, a package manager, settings, disks, an
editor. This one finishes the sentence in the two places the desktop was still
somebody else's: the window every other program runs inside, and the room the
machine is actually in when nobody is at the desk.

130 commits, 31 synui releases, three new packages.

## A terminal of our own

`syntty` is SynapseOS's terminal, and it is the default one — `Super`+`Return`,
`xdg-open` on anything `Terminal=true`, the start menu, the settings app's
Default Applications pane. It was built over five stages in this release, in
public, each one measured before the next was started.

**It links no GL at all.** wl_shm, xdg-shell, xkbcommon and libc; cells become
pixels on the CPU, in the exact `XRGB8888` a Wayland compositor wants, so the
buffer goes across with nothing in between. That is not a purity exercise — a
GL context is the one thing a live image cannot count on across unfamiliar
hardware, and a rescue disk that cannot open a prompt cannot rescue anything.
The binary is **359 KB** against kitty's 65 MiB, and the window is up in
**5.8 ms**.

It repaints **only what changed**: at 4K an interactive edit was 10.6 ms a frame
— 64% of a 16.7 ms budget, for a few characters — and is 68× less work now, the
same pixels either way. The VT parser was profiled where nothing profiles, in
the scroll path, and 2.56 MB of output went from 96.1 ms to 44.5.

The features that decide whether a terminal is usable at all are all here:
the **alternate screen** (vim, less, htop, man), the **pointer** — selection by
hand, and mouse reporting for the programs that ask for it — **copy and paste**
from both ends including OSC 52, **tabs** (a tab is a whole session, and costs
tens of kilobytes rather than a second process), a **config file** at
`~/.config/syntty/syntty.conf` because flags are not how anybody runs a terminal,
**key repeat** — Wayland sends none, the compositor hands over the rate once and
the client owns the timer — and **DECCKM**, the mode that decides whether the
arrow keys are `ESC [ A` or `ESC O A`, without which every full-screen program
gets the shape it did not ask for.

Two protocols beyond that. The **kitty keyboard protocol**, which is table
stakes rather than a win: in the legacy encoding `Ctrl`+`I` *is* Tab and
`Ctrl`+`[` *is* Escape, the same bytes, and nothing can tell them apart. And
the **kitty graphics protocol** — images in the terminal, which despite the name
has nothing to do with the GPU; it is an escape sequence, and `icat` works.

`syntty` and `synsh` together ship **OSC 133**, the de-facto semantic-prompt
protocol: the shell marks where its prompts, its input and its output begin, so
jumping between commands and copying one command's output are exact rather than
heuristic. They are the standard's marks, not ours, and every terminal that
already speaks them gets the same benefit from our shell.

It **follows the desktop theme** — the silver themes were the case that found
two bugs, because `dim` as a fixed blend toward the background lightens on a
pale theme, and a terminal that answers "what colour are you?" with the wrong
thing gets a program's own contrast decisions wrong for the whole session. It
answers `ESC ] 11 ; ?` honestly now, and it honours DECTCEM, so a program that
hid the cursor gets a window with no cursor drawn in it.

`--hold` arrived last, and with it the three call sites still pinned to kitty
for that one flag — System Status, Update System, and `syn-update`'s Install
button — moved across. Nothing in SynapseOS opens kitty any more, and
`synpkg remove kitty` works, which it did not.

## The couch face of the machine

`syn-arcade` is new, and it is four things: the **MangoHud overlay** driven from
a keybind *inside a game that is already running*, **game controllers** outside
Steam, **SDL mapping overrides**, and **big screen mode** — a ten-foot interface
for a television, on `Super`+`F10`, the pad's **Guide** button, or at login.

A television is not a monitor with a bigger number. It is four metres away,
driven with a controller by somebody who is not at a desk, and every desktop
convention fails at that distance. Big screen mode is one full-screen surface
of tiles: your **installed Steam library with its cover art**, sorted by what
you played most recently; Big Picture; whatever launchers and media players are
really on the machine; a browser, a terminal, the controller window; **music**;
**headlines**; and the machine's own switches behind **Start**. Nothing is
listed that is not installed.

**Music is the half that got the most attention, because it is what the room is
usually for.** There is a source — your **Plex or Jellyfin server**, found on
the network by broadcast; **YouTube Music**; internet radio; or the local
library — and the player is `cliamp`, which SynapseOS now packages and *drives*
rather than launches. Media buttons control whatever is playing without opening
anything, from the Start row.

> YouTube Music **needs no account to play**. Signing in is a browser, and it is
> for *browsing* — your own playlists, and a search you can type from the sofa
> with the on-screen keyboard. The two are genuinely separate things and the
> interface no longer implies otherwise.

A **visualizer** (projectM) is a tile, a Start row, and a chord — both stick
clicks, or `V` — because the visualizer is the one thing somebody turns on while
something else is already playing. It draws `cliamp`'s own FFT bands behind the
Now Playing row.

Two more things worth naming. **A tile press fills the television** — from a
sofa, a titlebar and a strip of wallpaper around the edge are the whole
difference between an appliance and somebody's computer left switched on. And
`syn-arcade fit` writes the gamescope line nobody remembers, so a game that
renders at 640×480 fills a 1440p screen instead of sitting in the middle of it.

**It steps aside rather than closing**, and it can now also be *closed* — a
layer-shell surface appears in no dock and no window switcher, so "hidden
forever" was the only exit it had.

Because a browser cannot be driven with words on a pipe, the controller becomes
a **mouse** while one is up (through `virtual-pointer-v1`, which synui now
offers), with an **on-screen keyboard** — and both stop the instant big screen
mode comes back. Everything else is words on a pipe, one per line, read by
exactly one process: no synthetic keystrokes, so stick drift cannot type into
every text field on the machine.

## The desktop

**Three Mac themes** — `macos26`, `aqua` and `platinum`, a Mac from three eras —
join the ten already on `Super`+`T`, thirteen now. They follow the Windows XP and 95 precedent: a
theme is a *style*, not a palette. What makes a window read as a Mac is that its
controls are on the left and its caption is centred; after that it is per-era,
Tahoe's flat glass, Aqua's pinstripes and glossy lights, Platinum's racing
stripes.

**The bar can be clear**, and its ink comes off the wallpaper rather than off a
theme. That started as macOS 26's menu bar and became everybody's: `bar_opacity`
is yours to set under any of the thirteen rather than one preset's private
property, and with the strip gone the clock's ink is measured off the picture
underneath so it stays legible. The dock and the widgets render through the same
compositor glass.

**A screensaver, and a lock screen that follows the theme.** `Super`+`Z` — five
modes (`blank`, `clock`, `starfield`, `slideshow`, `matrix`), off by default, so
nothing about an existing install's idle behaviour changes until you ask. It is
the fifth idle stage, so the power panel arms it and an application holding an
idle inhibitor holds it off. The lock screen defaults to your wallpaper, blurred
and dimmed, and the greeter inherits all of it — because the greeter *is* the
lock screen.

**Do Not Disturb** on `Super`+`Shift`+`M` hides the toasts *and* mutes the
chime. Suppressing only the drawing would leave the half people actually notice.

**Screens.** `display_mode` is one setting with three positions — `extend`,
`mirror`, `external` — cycled with `m` in `Super`+`D` or from Control panel ▸
Display ▸ Screens. Mirror forces the largest resolution every screen shares,
because overlapping two different panels and calling it mirroring shows one of
them a crop. `external` switches the built-in panel off, refuses when there is
no external screen, and re-runs itself on every hotplug, so unplugging the
television gives the laptop its screen back.

**Screen audio follows the screen** — `hdmi_audio = auto|on|off`, and `auto` is on
where it is wanted (a machine with a battery) and off where it is a nuisance (a
desk whose monitors never leave). It
keys off the ALSA **ELD**, never the sink name: a GPU advertises an HDMI sink per
pin whether or not anything is plugged into it.

**Text size is one desktop-wide setting**, family and scale, in the control
panel under Appearance — the same `font.state` the rest of the suite reads, so
there is no second opinion about it anywhere.

**The start menu lists applications now.** A Wine prefix invents new junk per
installer — uninstallers, readmes, registration forms, thirty-odd SDK tools —
and on one machine the Wine page was 65 entries of which 15 were programs. It is
15 now, by pattern for the shapes that cannot be enumerated and by a shipped,
curated list for the ones that can (your own file is read second, so `!name` puts
one back). Filtered entries are hidden from **search** as well, which is the part
that is more than tidying: typing "sims" and being offered *Uninstall The Sims*
one row above *The Sims* is a dangerous list to arrow through.

## Disks

`syn-disks` got the window its whole point depends on. The partition editor
existed only on the command line — add, delete, resize and **copy** are in the
window now, and copy exists at all.

The rest of it is one theme: **a format that fails should say why, before it
starts.** The Format menu offered six filesystems and could create three
(nothing said which); a write-protected stick went through the dry run, the
confirmation and polkit and failed at `mke2fs` with a sentence that reads like a
dead drive and means a switch on the side of one; a drive that latched itself
read-only *mid-write* was told to check a switch it does not have — a different
fact that must not share a sentence. A stick formatted exFAT would not mount
afterwards, and the format was perfect: this kernel could create the filesystem
and not mount it, which is now checked before it is offered.

Two more that matter because a filesystem is being written: **closing the window
no longer aborts the format**, and the window now stays for the write and says
why, rather than leaving quickshell to `SIGKILL` a `mkfs` half way through.
And a stick you formatted **belongs to you** afterwards — `mkfs` runs as root
through polkit, so its root directory did too, and the drive came back mounted
and unwritable to the person who had just formatted it.

## Files

**Copying was 147× slower than `cp`** — an `fsync` per file, 2000 small files in
12.25 s against 0.08 s, and the whole of "copying seems slow" on a USB stick. It
is 0.08 s now.

Everything long says how long is left, in the unit that decides it: recursive
deletes report as they go rather than as one record at the end (emptying a trash
folder off a stick is minutes of silence otherwise, and a GUI silent that long
cannot be told from a hang), and the progress panel stopped counting its own
headers as failures.

**Copying a folder into the folder that contains it** — the ordinary way to
duplicate one — produced no copy, reported "4 done, 0 failed", and scattered
`f (copy).txt` through the *original*. Fixed.

`F9` puts the left panel away (Dolphin's key, and Nautilus'), and it is
remembered. A USB stick with **no partition table** — a filesystem straight on
the device — appears under Removable Devices, where it was mounted, browsable
and invisible.

## Software, updating, installing

**`synpkg` gates an upgrade on the Arch news** and offers a reboot when the
kernel moves — two things pacman has never done, and that a graphical Update
button makes matter more, not less. `status` now reports the kernel **staged for
boot**, which is a different file from the one installed and the one running, and
the one that actually strands a machine. `/etc/pacman.d/hooks` is registered as
a hook directory: `libalpm` seeds only the `/usr/share` one, so every
transaction ran with the drop-ins invisible.

**`syn-update` asks for your password once.** `sudo`'s timestamp is five minutes
and a full rebuild is much longer, so an apply used to stop at a prompt three or
four times, long after anyone was still watching it. It also refreshes the
databases the cheap way, and `fetch`, `synapse-wallpapers`, `syn-arcade`,
`cliamp` and `syntty` are all updatable — three of them were on every installed
system and updatable on none, with nothing saying so.

## Everything is optional now

**Custom means every package.** Eleven of our own were installed whatever you
answered — `synpkg`, `synfiles`, `syn-settings`, `syn-disks`, `syn-edit`,
`syntty`, `syn`, `syn-model`, `syn-firstboot`, `syn-confine`, `fetch` — and the
old Custom questionnaire could not decline any of them. The reasons each was
unconditional were all good ("a desktop where clicking a folder does nothing is
not a smaller system, it is a broken one") and all arguments for a **default**,
not for a rule.

All twenty-five are checkboxes on one page now, the compositor and the package
manager included. What is still forced is only what pacman would force anyway:
`synui` hard-depends on `syntty`, `synnet` and `vibe` on `synapd`, `vibe` on
`syn-confine`, `syn-firstboot` on `syn-model`. Those are turned back on **and
named**, before anything is installed, so the summary and the machine agree — a
checkbox that silently un-ticks itself is worse than one that was never offered.

```
  SynapseOS packages — everything the system is made of

  [x]  1) SYNAPSE UI    the desktop     [x] 14) Models        fetch AI models
  [x]  2) synapd        the AI daemon   [x] 15) First boot    first-run setup
  [x]  3) synsh         the AI shell    [x] 16) Sandbox       Landlock jail
  …
  Toggle [numbers, 'all', 'none', Enter = accept]:
```

**And an installed SynapseOS had no web browser.** The live ISO ships Firefox;
the machine installed from it did not, unless the Full preset happened to pull
one in as `nexus-chat`'s dependency. There are five pages of ordinary software
now — web and communication, audio and video, office and graphics, development
and admin, games and launchers — forty-seven programs from the Arch
repositories, with Firefox ticked by default on every preset but Minimal.

It installs **last and in its own transaction**, warns rather than fails, and
retries one at a time so a single renamed package fails alone and is named. A
shared transaction is how one bad name takes every SynapseOS package with it,
which is what `samsung-m2020` once did to the Full preset.

The graphical installer draws the same table as the same checkboxes, and every
row is a profile key, so an unattended install picks the same set:

```nix
preset = "custom";
comp = { synui = true; chibi = false; tepris = false; };
sw   = { firefox = true; vlc = true; docker = true; };
```

The rest of the installer: one branded screen at boot instead of two, a
**Custom** page in the graphical installer (an unanswered question is `read -r`
on the terminal *behind* the window, so the install stops with nothing on screen
saying why — the test suite now checks both directions of that for all seventy
keys), and **pickers for the region** — locale, timezone, keymap and layout are
four lists rendered from records `syn-install` prints, with a filter box that
doubles as the free-text field. Picking a language sets the font pack, so a
Japanese install picked off a list no longer arrives with no CJK font on it.

**CachyOS Proton has never once installed.** Two independent bugs: the filename
lookup read a zstd-compressed database with `tar -tzf`, which fails silently and
returns the pinned fallback URL every time; and the keyring was fetched before
its key was trusted, so `pacman -U` refused it for unknown trust. Both fixed.
Both updaters also refresh with `-Syy` before resolving, under the
authentication they already ask for.

**The ISO shipped four wallpapers no install could deliver.** They were in
`packages.x86_64` — the live image — and in neither of `syn-install`'s target
lists, so they worked on the media and were absent on every machine installed
from it, which is the one shape that testing the ISO cannot reveal.

## The gates

`tools/preflight.sh` is new, and it **refuses a commit that cannot ship**. Four
release bugs kept coming back, each silent, each surfacing a long way from its
cause: a source edit with no `pkgrel` bump (pacman compares `pkgver-pkgrel`, so
the fix simply never installs); a component in one build list and not the other
five; a package built into the ISO's repo but never installed onto the image, or
the reverse, which kills `pacstrap` fifteen minutes in. It runs before every
commit now.

Two CodeQL TOCTOU alerts were real and are fixed — a name checked and a name
opened are two different files, in `synfiles`' `du` and its move path — and the
guard that was supposed to catch that shape only looked one way, so it walked
past the bug CodeQL then found.

## Fixed

- Closing a terminal opened another one. `Super`+`Return` ran a
  `syntty || kitty || foot || …` fallback chain, and `||` means "the previous
  one exited non-zero" — which for a terminal is the exit status of the shell
  inside it. Pressing `Ctrl`+`D` on a failed command therefore opened the next
  terminal on the list.
- Windows opened on a screen that was **switched off**: a disabled output stays
  in the layout, so saved geometry kept re-homing windows onto a blanked laptop
  panel — the application opened, took focus, and was invisible.
- `kitty` could not be uninstalled, and the window would not say why: `synpkg`'s
  GUI swallowed every failed transaction.
- Firefox kept rounded corners under the square-chrome themes, and a light theme
  never announced itself as light, so it intermittently lost its theme colour.
- Sixty panel colours were still picked against the old navy, and the Win95
  calendar's text was 1.03:1 against its own panel — text that is not there at
  all.
- A headless `synui` (a test run, a nested session) **re-themed the real
  desktop**: theme application writes `$HOME/.config`, gsettings and kwriteconfig
  over the session bus, and none of that is isolated by a private `HOME`.
- The mixer's `(•)`/`( )` radio had no click target — the one thing drawn as a
  button was the one thing that was not one.
- `syn-edit`'s Save button could refuse but could not ask for a name, so
  New → type → Save was unsaveable from the window; and Find and Replace, in
  insert mode, **typed `/` and `:%s/` into the document**.
- The `synapse` group is a package fact now, not an installer step — every
  install logged four tmpfiles failures resolving it.
- `cliamp`'s build leavings made `syn-update` refuse to update, reporting local
  modifications nobody had made.

## Known issues

- The live ISO carries **no AI model** by design; `synapd` runs in shell-assist
  mode there and `syn status` reporting "model ✗ not installed" on live media is
  expected. The installer asks which model you want and downloads it onto the
  target.
- `kitty` is still installable and still works — it is simply no longer what
  anything opens by default.
