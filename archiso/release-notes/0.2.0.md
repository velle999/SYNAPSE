The desktop release. 0.1.9 was built and then held back over a rendering bug in
VMs; this is that release with the cause found rather than worked around.

A minor bump rather than 0.1.10 because the desktop is not the one 0.1.9
shipped: waybar is gone, the compositor moved to wlroots 0.20 and renders
through scenefx 0.5, and cursor themes, event sounds and desktop widgets are all
new.

## The bar and the desktop are ours now

**waybar has been replaced by a native [quickshell](https://quickshell.org/)
shell.** One bar per monitor, live across hotplug, with per-monitor settings, a
right-click settings menu and auto-hide on an edge dwell. The start button and
menu moved into it, and `menu.c` — the in-compositor menu that existed only
because waybar's GTK could never take keyboard focus — was deleted.

**Desktop widgets** (`Super`+`Shift`+`A`): an audio visualiser, a system
monitor, a big clock and a quick-launch strip, with a manager panel and a
per-widget CLI. **All off by default** — an upgrade should not redecorate a
desktop nobody asked it to.

**Desktop icons** with drag-to-place, persistent placement, and arrange by name,
type, size or date.

## Themes, cursors and sounds

**Cursor themes** (`Super`+`Shift`+`P`) — a picker, plus `synui-cursor` to
install one from any `.zip`/`.tar.*` or directory. It knows the difference
between a ready-to-use theme and a source tree, which is the thing that actually
wastes people's afternoons on gnome-look.

**Event sounds** (`Super`+`S`) — ten events, from login to USB insert, with a
per-event sample picker and `synui-sound install` for themes. **Silent by
default**, and it stays silent until you turn something on.

**Themes** (`Super`+`T`) — six riced palettes on top of SYNAPSE, Dark, XP and
95, applied across synui's chrome, the bar, GTK, Qt/KDE, `foot` and Firefox. A
theme switch repaints the running bar with no restart.

## Rendering

Ported to **wlroots 0.20** with **scenefx 0.5**. Window effects gained
`shadow_spread`, an optional `glass_halo` ring, and `clip_csd_margin` — which
crops clients that draw their own shadow, so every window's ring is the one the
compositor draws. HDR is now detected from the monitor's EDID rather than
assumed from a 10-bit plane.

**Window effects are off by default on a fresh install.** Effects on a machine
that cannot afford them is a bad first impression that looks like breakage.

## Install

**LUKS2 full-disk encryption** on the erase paths, managed afterwards with
`syn-crypt` (`status`, `add-key`, `change-key`, `backup-header`). `/boot` stays
a separate plain partition on purpose: inside LUKS, GRUB has to unlock it, and
GRUB can only open LUKS2 volumes using PBKDF2 — not the argon2id that makes
LUKS2 worth having.

**Dual-boot** on UEFI: a non-destructive install into existing free space,
reusing the machine's ESP.

Two installer bugs worth naming, both found by installing from the ISO rather
than reading it. The language menu drew five of its fifteen entries as boxes —
the console font is Latin-1 Terminus and no VT font can cover CJK — so the
labels are English now. And the timezone prompt wanted a tzdata `Region/City`
and silently installed UTC when it did not get one; it takes `CST`, a bare city
name, or a number from a list.

## The VM rendering bug

synui forced software rendering in **every** VM, so every VM ran on llvmpipe
through the surfaceless EGL device — and that is where layer surfaces corrupt:
the bar's badge drew over itself and modules went blank when they repainted.

Any hypervisor with 3D enabled has a working GPU. synui now tries hardware and
falls back only if the renderer will not come up, which is a test of what works
rather than a guess from a device name — and it also covers nouveau and
machines with no DRM node, which the old guessing was written for.

Measured in a guest, sweeping the pointer along the bar: forced software
corrupts it and does not recover; the same guest on its GPU, and the same guest
with no 3D once the forcing is gone, both change zero pixels.

  [Gaming](https://github.com/velle999/SYNAPSE/wiki/Gaming) wiki page

- Night light back on the output state, where it survives window effects
- Monitor grid columns align; `outputs.conf` positions are taken verbatim
